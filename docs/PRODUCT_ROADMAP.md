# 「墨芽童伴 · InkSprout」儿童护眼故事机 + 滚轮游戏机产品路线规划

基于 **Waveshare ESP32-S3-ePaper-3.97** 硬件底座（`ESP32-S3R8 16MB Flash / 8MB PSRAM` + `3.97" 800×480 SSD1677 墨水屏` + `ES8311 音频编解码 & 麦克风 & NS4150B 功放` + `三向拨轮开关` + `TG28 锂电管理` + `QMI8658 六轴` + `PCF85063 RTC` + `SHTC3 温湿度` + `MicroSD`）。

## 二、 双龄段人群内容与交互分层设计

### 1. 学龄前启蒙段（3–6 岁 · 幼儿园小中大班）
- **认知特征**：识字量少（0~300 字）、精细动作发育中、抗挫折能力弱、喜欢模仿说话与重复儿歌。
- **产品体验设计**：
  - **绘本共读**：左图右大字（24px/32px 圆润黑体）+ 八音盒旋律/TF 卡真人语音伴读 + 读后 1 道安全/习惯常识小问答。
  - **滚轮启蒙游戏**：《滚轮配配乐》（立式摩天轮转盘选动物/数数/古诗，答错温柔引导不扣分）、《海底小潜艇》（三水道慢节拍接海星，中按发泡泡把障碍变奖励）。
  - **语言表达启蒙**：《变声小鹦鹉》一键录下孩子背古诗或自编故事，用花栗鼠/大狗熊变声逗乐，激发开口表达欲。

### 2. 学龄成长段（6–12 岁 · 小学一至六年级）
- **认知特征**：自主阅读爆发期、口算与逻辑推理敏感期、渴望高分挑战与勋章收集。
- **产品体验设计**：
  - **科普/历史/互动游戏书**：《曹冲称象》《司马光砸缸》《天文月相百科》及滚轮多结局《森林勇者奇遇记》，外接 TF 卡畅读整套成语故事、十万个为什么。
  - **滚轮思维训练营**：《数字摩天轮》（乘除逆向填空闯高塔）、《翻转记忆牌》（3×4 空间记忆）、《滚轮打砖块》（旋钮挡板角度预判）、《森林密码锁》（Mastermind 逻辑破译）。

## 三、 四阶段产品演进路线图（MVP → V1.5 → V2.0 AI → V3.0 量产）

### Phase 1：MVP 离线完整闭环固件（当前 V1.0 已交付）
- **硬件全通**：打通 `TG28` 多路 LDO 供电控制、`SSD1677` 300ms 局刷与防残影调度、`ES8311+NS4150B` 音频合成/WAV 流播放/麦克风录音变声、全字库 20,902 汉字内嵌 Flash、三向滚轮零延迟状态机、六轴摇一摇盲盒、RTC+温湿度儿童房看护。
- **内置应用**：绘本故事屋（8 册内置 + TF 卡 TXT/WAV 同步伴读）、启蒙游乐园（2 款）、益智挑战营（4 款）、变声小鹦鹉、星星荣誉墙、家长护航站。

### Phase 2：V1.5 无线/USB 传书工坊与外壳结构工程化（传书链路已提前交付！）
- **双通道免拔卡传书工坊（已完成并集成至固件）**：
  - **USB 电脑免驱优盘模式 (`TinyUSB MSC`)**：插上 Type-C 线秒变 `INKSPROUT` 优盘（自适应外部 MicroSD 卡与机内 3.8MB 磨损均衡闪存盘，无 TF 卡亦可拖拽传书），附带电脑端 `tools/send_story.py` 自动配音导入工具。
  - **设备 Wi-Fi 热点扫码传书 (`SoftAP + Captive Portal + 双二维码`)**：手机扫墨水屏二维码连入 `InkSprout-Kids` 免密热点即弹出传书网页，内置在线写绘本、GBK/UTF-8 防乱码识别、手机浏览器 `AudioContext` 自动将 MP3/M4A/WAV 重采样为 16kHz 护耳单声道 WAV，以及父母亲情麦克风讲故事录音上传。
- **儿童安全圆角外壳（3D 打印 / 手板验证）**：
  - 基于微雪官方结构图 `ESP32-S3-EPAPER-3_97.stp` 设计 **双耳小熊圆角防摔硅胶/PETG 外壳**，重点加宽顶肩滚轮防滑齿纹、内置 `2030` 腔体喇叭（接 `H2 MX1.25`）与 `1500mAh~2000mAh` 聚合物锂电池（接 `H3 MX1.25`，带 NTC 热敏保护）。
  - 屏幕表面贴合 **PMMA 磨砂防眩抗压盖板**（保护 `0.92mm` 玻璃基板防跌落碎屏，参考墨水屏手册跌落与静电规范）。

### Phase 3：V2.0 AI 互动故事引擎接入（已提前完成并合入固件！）
- **家庭路由器 `APSTA` 扫码配网 + 定制化 AI 睡前故事扭蛋机（已交付于 `app_ai_story.c` & `app_transfer.c`）**：
  - **手机扫码一站式配网 (`http://192.168.4.1`)**：支持扫描周围 2.4GHz 家庭路由器、保持热点不断线实测路由器连接分配 IP、设置宝贝专属昵称与年龄分阶（3-6岁 / 6-12岁），并一键切换 **小智 AI / DeepSeek / 通义千问 / 豆包 / 硅基流动 / 本地 Ollama**。
  - **滚轮三步扭蛋编故事**：
    1. 第一圈滚轮选主角（勇敢小恐龙 / 宇航员小兔 / 侦探小猫咪 / 宝贝自己等 8 项）
    2. 第二圈滚轮选奇幻场景（云朵糖果城堡 / 月球环形山基地 / 海底发光森林等 8 项）
    3. 第三圈滚轮选成长主题（温柔晚安 / 好好刷牙 / 勇敢独立不怕黑 / 分享合作等 8 项，支持摇一摇随机组合）
  - **小智 AI 6位码免 Key 语音流 + 大模型读后问答**：小智模式下屏幕弹出 6 位绑定码，经 `WSS + esp-opus` 边收文字边将 Opus 语音解码落盘为 `.wav`；通用大模型模式下自动生成分龄四页绘本 + 读后三选一问答 + 可选云端 TTS `.wav`，生成后立即关闭 Wi-Fi 射频并永久沉淀至本地书架离线重听！
- **绘本阅读页「滚轮生字拼音 · 华文楷体田字格放大点读」与生字卡片盒（已交付于 `app_word_study.c` & `hanzi_study_pack.bin`）**：
  - 全量 `20,902` 汉字拼音索引 + 儿童高频多音字语境词库 + 标准四线三格拼音 + `3,769` 常用字 `104×104` 华文楷体田字格 + `1,388` 个普通话带调音节 `16kHz Opus` 离线真人语音库（支持单字即点即读、文中双字词组连读、生字本收藏与「听音找字」闯关）。

### Phase 4：V3.0 商业化与合规量产准备（第 11–16 周）
- **儿童硬件安全合规**：外壳无锐边与小零件脱落测试（GB 6675 玩具安全标准）、锂电池过充过放与 `TG28` NTC 温控标定、SRRC/CCC 认证评估。
- **主题内容卡生态**：推出实体或数字主题 TF 故事卡（如《西游记少儿连环画卡》《古诗词飞花令卡》《幼小衔接思维 100 关》），提升单机复购价值。
